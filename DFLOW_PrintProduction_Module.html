Stock Choice & File Preparation

Colour Mode
CMYK for all print output. RGB only for screen proofs.
Bleed
General: 3mm all edges up to A3 size, Wide format: 5–10mm
CMYKHub: 2mm all sides, 5mm for double sided wide format
Ink Coverage
General: Coated ≤ 340% TAC. Uncoated ≤ 260%.
CMYKHub: 260% (C60 M50 Y50 K100)
Layer Sequence
Printed: CMYK Artwork → White Ink (if any) → Varnish → Embellishments (foil, spot UV, emboss) as separate named layers or pages.
Unprinted (Knife, Cut, Crease, Fold) must be on the top layer over the varnish.

The Artfix Workflow

Pre-checks · Artfix · Verification

1. Pre-Artfix Checks
  • Confirm job spec: size, kinds, side, finishing
  • Check the brief
  • Check customer file format (PDF / AI / INDD / PSD)
  • Run DFLOW preflight profile in Acrobat
  • Log initial issues in job notes
  • Flag to client if critical
2. Artfix
  • Processing as per customer's brief
  • Convert colour mode (RGB → CMYK)
  • Embed fonts / outline text
  • Fix overprint & knockout settings
  • Apply output intent (ICC profile)
3. Post-Artfix Verification
  • Run DFLOW preflight profile in Acrobat
  • Zero critical errors before delivery
  • Soft-proof visual check vs brief
  • Apply DFLOW file naming & folder structure
Detail workflow in P:\Print Services Resources\Platform\Artfix Workflow.pdf

Basic Artfix Operations

1. Resize & Bleed
  • Set document to correct trim size
  • Add 3mm bleed on all edges
  • Extend background/images to bleed boundary
  • Reposition live content inside 5mm safety zone
2. Colour Mode
  • Convert RGB images: Edit → Convert to Profile
  • Target: ISO Coated v2 / FOGRA39 (offset)
  • Check & reduce ink density if TAC exceeded
  • Spot colours: verify Pantone name
3. Fonts
  • Embed: File → PDF Export → Include All Fonts
  • Outline all text (Type → Create Outlines)
  • Check DFLOW font licensing policy first
4. Embellishment Page
  • Add separate page/layer named e.g. 'Foil' or 'SpotUV'
  • 100% single solid colour
  • Vector for foil/emboss

DFLOW File Naming & Folder Structure

Naming convention

[JobNo]_[End Customer Name/Event]_[Order Code]_[Dimension]_[Option]_[Version Number].pdf
Example: A001-2605-001_Anzac Card_CARD_210x185_01_V1.pdf,
A001-2605-001_Anzac Card_CARD_210x185_02_V1.pdf
Folder Structure
Root Path/ eg. Prepress
Platform/ eg. Printready
Customer root folder/ eg. A001
Year and Month/ eg. 2026-05
Job folder/ eg. A001-2605-001
ORIGINAL
WORKING
FINAL
Key Rules
  • Title case only for end customer/event
  • Increment version on every revision (V1, V2…)
  • Add suffix "_PROOF" before "_Vn" for proof file

Overprint & Knockout Settings

Profiles · Output Intent · Overprint

Overprint
  • 100% K black text or small object - prevents white halo on mis-register
  • Use for: rich black solid backgrounds (C60 M50 Y50 K100)
  • Check: Acrobat Output Preview → Simulate Overprinting
  • Never overprint white - it will disappear on press
Knockout (Default)
  • Standard for most objects - prevents ink stacking
  • Check in Acrobat: View → Show/Hide → Overprint Preview ON
  • Use Output Preview → Separations tab to inspect each plate

Preflight Profile & Output Intent

DFLOW Preflight Profile

Applying the profile:
Tools → Print Production → Preflight

  • Select DFLOW Standard profile from list
  • Run Analyse and Fix where available

Errors vs warnings:

  • Critical errors MUST be resolved before delivery
  • Warnings: review and document if waived
Output Intent

What it is:

Embedded ICC profile defining the printing condition. Ensures colour accuracy across RIP and press workflows.

DFLOW used profiles:

  • FOGRA39 - Coated offset (ISO 12647-2)

Soft Proof Check Before Delivery

Soft Proof · Naming · Font Policy

Size & Bleed
Trim size matches job spec exactly. Bleed as per request. Safe margin observed.
Colour
Enable Acrobat soft-proof (View → Proof Colors). Compare to approved proof or brief. No unexpected colour shifts.
Content
No content changes, missing or added, except as requested in the brief.
Images
Images sharp, no pixellation, no low-res. Placement matches approved layout.
Brief
Ensure all requested brief items are delivered.
Zero Errors
Preflight report: zero critical errors. Warnings reviewed and logged.

Font Licensing & DFLOW Policy

Desktop License
✓ Embed OK

Standard commercial license. Permits embedding in PDFs for print. Most common type.

Web-Only License
✗ Cannot Embed

Licensed for screen use only. Must obtain print license or substitute font.

Free / Open Source (OFL)
✓ Usually OK

Apache fonts (e.g. Google Fonts) typically allow embedding. Confirm per font.

Embedding Restricted
✗ Outline Instead

Font has embedding restricted bit set. Outline all text - do not attempt to embed.

DFLOW POLICY: Never share fonts with the customer. Use only fonts from Adobe Fonts or fonts supplied by the customer.
