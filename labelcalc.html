Layouts

With "Optimize layout usage" on, auto-generate can split kinds across several shared layouts - e.g. with 6 Up Across, two pairs of kinds can each get their own 3+3 shared layout, instead of forcing everyone into a single shared layout. Turn it off to go back to the simpler search: isolate some kinds onto their own full-width layout, and combine everything else into just one shared layout. Adjust Up Across/sheets by hand afterward if you want - that switches to manual mode.

With "Allow a kind to span more than one layout" on, auto-generate instead builds layouts round by round: each round apportions all the lanes among whatever kinds still need production (weighted by how much they still need), runs just enough sheets to exactly finish whichever kind is tightest that round, then carries every kind's leftover into the next round - so a kind can appear across as many layouts as it takes, each time paired with whatever else still needs finishing. This overrides "Optimize layout usage" while on, and usually gives the lowest waste of all the modes, at the cost of more separate layouts/plates.

Total sheets = sum of sheets across all layouts (each layout is its own plate/run). Total produced per kind = sum across layouts of Up Across × repeat-to-length × sheets. Auto-generate rebuilds the layout set from scratch whenever quantities or sheet setup change - it tries every combination of "isolate this kind on its own full-width layout" vs "combine it in with the rest," and keeps the split with the least total overproduction. The per-layout "Auto-fill sheets" button is a manual-mode tool for topping up one layout's sheet count based on what's still short after the others.
